## 🧰 Contoh Kerjaan

```python
# network_check.py — contoh gaya kerja saya 😎
import subprocess

devices = {
    "Gateway MikroTik": "192.168.88.1",
    "Core Switch Cisco": "192.168.10.1",
    "Server Debian": "192.168.10.10",
    "Server Ubuntu": "192.168.10.11",
}

for name, ip in devices.items():
    status = subprocess.run(
        ["ping", "-c", "1", "-W", "1", ip],
        capture_output=True,
    ).returncode
    print(f"{'🟢 UP  ' if status == 0 else '🔴 DOWN'} | {name:<20} | {ip}")
```
